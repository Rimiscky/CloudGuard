## Déposer un fichier depuis GitHub

1. Ouvrir le dossier `assurio-g3/00_a_deposer/` sur GitHub.
2. Cliquer sur **Add file → Upload files** et glisser les fichiers.
3. En bas, écrire en une ligne ce qu'est le fichier (ex. « Profilage L2 v1, à relire »), puis **Commit changes**.
4. Prévenir Claude dans la conversation : il récupère le dépôt et range le fichier dans le bon dossier après relecture.

Pour remplacer un fichier existant, déposez-le avec **le même nom** dans son dossier : GitHub garde l'historique des versions.
